TITLE
=====
Lecture 2: The File Is The Program — DOS Game from Scratch (assembly, COM vs EXE)


DESCRIPTION
===========
A COM file has no header. None at all. DOS finds a free segment, copies the
file into it, and jumps to the first byte — so if you open the file in a hex
editor and change five bytes, the program changes. In this lesson we do
exactly that: HELLO becomes WORLD without the assembler running once, and the
source still says HELLO afterwards.

Along the way, the thing nobody shows beginners: what an instruction actually
IS. Eighteen bytes come out of ten lines of source, and every one of those
eighteen can be pointed at and named — this three-byte group is "mov dx, msg",
that two-byte one is "int 21h", and those last six are the letters themselves.

  - writing ten lines of assembly, and what every one of them is for
  - eighteen bytes: the entire program, on one line
  - reading the bytes back against the source, one instruction at a time
  - patching the file with a hex editor, and running it again
  - why org 100h, and what DOS actually does when it loads a COM
  - the same program as an EXE, and what it has to add
  - one line of source decides which kind of file comes out
  - eighteen bytes against eighty-one, and where they went

The assembler is flat assembler, and it is inside the source repository — free
to use and free to pass on. There is no linker: FASM writes the finished file
itself, which is why the choice between a COM and an EXE is a line in the
source rather than a flag on a command line.

  format binary as 'com'      ->  HELLO.COM,  18 bytes
  format MZ                   ->  HELLO2.EXE, 81 bytes

That is the whole fork in the road, and it is in the program, where you can
see it.

Source, both files, runs on its own:
https://github.com/KirinDenis/wire-city-2/tree/main/LESSONS/L02

Tools: DOSBox 0.74-3, flat assembler (ships in the repository), and Volkov
Commander as the hex editor — this machine has no DEBUG.EXE, and VC is the one
tool in DOS that both shows bytes and changes them.

OWL FLY III on your own site

This is an ordinary host page. Everything below the heading is a single <iframe>: the emulator, the game and the multiplayer link to the relay all live on the embedded page, so the host builds and runs nothing.

Copy this

<iframe src="https://kirindenis.github.io/wire-city-2/owlfly3_embed.html"
        style="width:100%;aspect-ratio:4/3;border:0;background:#000"
        allow="fullscreen; gamepad; autoplay; cross-origin-isolated"
        allowfullscreen title="OWL FLY III"></iframe>

Multiplayer works out of the box: every player on every site that embeds the game meets in the same sky on our relay. To give your players a sky of their own, add a room name: owlfly3_embed.html?room=yoursite.

Players click the game once to give it the keyboard. The browser tab must stay visible, because browsers pause hidden tabs and the jet stops with them.
